# AI伯乐行为证据采集埋点清单 v1.0

适用模块：倾听之洲（聊天观察）、想象之洲（故事共创）、创造之洲（深海基地重建）、未来之洲（职业模拟器）。

## 当前代码接入状态（1.0）

四个模块入口均已加载统一账号/证据桥，并已在真实任务完成点启用 6 个低频事件：

| 模块 | 已启用事件 | 触发时机 |
|---|---|---|
| 倾听之洲·聊天观察 | `narrative_evidence` | 一次聊天正常结束时汇总一次 |
| 想象之洲·故事共创 | `story_contribution` | 孩子独立提交故事结尾时 |
| 创造之洲·深海基地重建 | `ecology_strategy`、`spatial_solution`、`mediation_response` | 三个关卡分别完成时各一次 |
| 未来之洲·职业模拟器 | `workday_process_summary` | 一天职业流程全部完成时汇总一次 |

下文其余事件为下一轮可按研究问题开启的候选事件。默认不全开，避免重新形成“采集很多但无法解释”的日志堆积。

## 总体规则

1. 不使用问卷自评，不因“选择了某个答案”直接判定天赋；只记录孩子在真实任务中的操作、表达、修改和持续行为。
2. 报告只统计行为频次、行为类型、跨任务重复性和证据来源覆盖度。原始行为必须可回溯。
3. **禁止将行为直接换算成分数、百分比、排名或能力高低。**“强正向证据”表示行为清晰、主动且可复核；“参考证据”表示线索较弱、由提示产生或只出现一次。
4. 同一智能的相对突出程度由证据组合判断：优先看强证据数量、不同类型数量、跨模块复现和时间稳定性；不得用固定加权公式。
5. 每条事件只保存：统一账号ID、事件类型、发生时间、来源模块、候选智能（最多3个）、证据级别、通俗行为摘要、必要原始证据、任务上下文。删除无关点击流、完整页面轨迹和重复中间状态。

## 精简后的模块事件

| 模块 | 仅保留的核心事件 | 不再进入统一报告的数据 |
|---|---|---|
| 倾听之洲 | `topic_initiated`、`reflection_elaborated`、`narrative_evidence` | AI回复全文、天气装饰状态、每次普通点击、无实质内容的寒暄 |
| 想象之洲 | `story_contribution`、`story_revision`、`character_perspective` | AI原始响应、重复渲染状态、每个字符输入过程、无关UI点击 |
| 创造之洲 | `ecology_strategy`、`spatial_solution`、`mediation_response` | 空白点击明细、鼠标坐标流、每次旋转日志、重复失败的逐条流水 |
| 未来之洲 | `scenario_decision`、`decision_revision`、`workday_process_summary` | 页面浏览轨迹、装饰按钮点击、逐秒计时、与证据无关的完整操作日志 |

## 统一事件结构

```json
{
  "module": "story",
  "event_type": "story_revision",
  "occurred_at": "2026-08-19T10:20:00+08:00",
  "evidence_level": "strong",
  "intelligence_candidates": ["linguistic", "intrapersonal"],
  "behavior_summary": "主动发现故事前后矛盾并修改原因",
  "raw_evidence": {
    "before": "小船已经沉了，后来他们坐着小船回家。",
    "after": "他们修好另一艘旧船，再一起回家。"
  },
  "context": {
    "task_id": "story-42",
    "turn": 5,
    "prompted": false
  }
}
```

`raw_evidence` 只保留支撑报告结论所必需的片段，不应复制整段会话或完整操作流水。
