# 四模块电影感入口封面

## 范围与模式

本 brief 只约束深海基地重建、故事共创、职业体验和小新聊天四个入口封面，不覆盖模块内部操作页，也不替代根目录 `DESIGN.md`。四个入口均采用 **Persuade / Experience** 混合模式：第一屏先让儿童进入故事世界，再以一个明确主行动进入任务。

## 已构建的共同视觉语言

四个封面采用原创、高品质的 3D 家庭动画电影感，不复刻任何具体影视 IP、角色、构图或标识。桌面端使用全幅叙事场景：左侧是高对比中文标题、简短故事引子和主行动，右侧保留角色与世界焦点。深色渐变从左向中部过渡，使文字无需额外大卡片也能清晰阅读。

中文主标题使用清晰、粗重的系统中文字体栈（`Microsoft YaHei UI`, `PingFang SC`, sans-serif），而不是难辨认的花体或伪手写字。一级标题为白色，关键词可使用暖金色；所有主按钮统一使用珊瑚橙 `#ff765f`，形成跨模块的行动识别。

## 四个独立世界

- **深海基地重建：** 风暴后的蔚蓝基地、珊瑚建筑与沫沫构成救援故事。重建路线必须位于左侧深色内容区内，在标题、故事引子和主行动下方，而不是横跨角色或场景焦点。
- **故事共创：** 发光魔法书打开通往想象世界的入口；人物和幻想场景位于右侧，左侧文案强调“共同创作”而非工具功能堆叠。
- **职业体验：** 职业群岛与探索角色形成可出发的冒险地图；入口只承诺开始探索，不在封面塞入完整职业分类。
- **小新聊天：** 温暖树屋会客厅表达安全、亲近和可倾诉；小新及树屋生活细节位于右侧，左侧保持清晰问候与单一聊天行动。

## 布局与响应式

桌面端保持左文右景。文案区应占约半屏以内，标题、描述、主行动沿同一左轴排列；角色的脸、视线和关键道具不得被文字或路线卡遮挡。深海的三项重建路线收在左侧深色区下方，卡片紧凑并从 1 到 3 顺序清晰。

在约 `760–900px` 以下切换为单列电影海报布局：背景仍保持全幅，角色焦点留在上半部或中上部，文案落到下方深色区域并左对齐。主按钮在窄屏可扩展到容器宽度。标题必须正常换行，不截断、不溢出；说明文字可缩短，但不可覆盖角色面部。深海任务路线在手机端纵向排列，辅助说明可隐藏或截断以保障主任务名称。

## 组件规则

### 标题

- 使用粗体系统中文，桌面端以 `clamp()` 控制尺度，行高约 `1.02–1.18`。
- 一级信息白色，第二行或关键词可使用暖金 `#ffcf74` / `#ffd173`。
- 可使用低透明度深色文字阴影增强复杂背景上的可读性。

### 主行动按钮

- 背景统一为珊瑚橙 `#ff765f`，文字白色，字重粗。
- 采用圆润胶囊或与模块既有组件一致的柔和圆角；悬停只做轻微上移、颜色提亮与阴影增强。
- 每个封面只突出一个主行动，次级入口不得与其争夺颜色和体量。

### 叙事辅助区

- 半透明深海蓝或模块对应深色表面只用于必要的路线、状态与次级信息。
- 深海路线使用紧凑三步结构，图标、名称、短说明和序号均需一眼可扫读。
- 避免将首屏重新做成多张等权功能卡拼贴。

## Do / Don't

### Do

- **Do** 让每个模块拥有可辨识的独立世界，同时复用左文右景、珊瑚橙主按钮和粗体中文标题。
- **Do** 把角色表情、视线、光源和关键道具作为画面叙事中心。
- **Do** 使用渐变遮罩保证标题、说明和行动按钮达到稳定对比度。
- **Do** 在移动端把文案落到下方，并通过 `background-position` / `object-position` 保留角色焦点。
- **Do** 保留键盘 `focus-visible`、减少动态偏好和足够触控尺寸。

### Don't

- **Don't** 使用难辨认的花体、装饰字或由图片生成器绘制的中文标题。
- **Don't** 在背景图中生成文字、Logo、水印、按钮或界面卡片。
- **Don't** 复制迪士尼、皮克斯或其他具体 IP 的角色、商标与标志性构图；只保留原创家庭动画电影的情绪和制作质感。
- **Don't** 用发光玻璃卡、随机渐变和无关装饰堆出“AI 感”。
- **Don't** 让路线卡、导航或次级功能遮挡角色面部及核心场景。

## 生成资产来源要求

所有封面栅格图必须为项目原创生成资产，画面本身不得包含文字、Logo 或水印。每个生产用图片旁必须保留同名 `.webp.json` prompt sidecar，记录完整生成提示词和来源信息；移动、重命名或替换图片时须同步处理 sidecar。页面中的中文标题、按钮与无障碍文本必须由 HTML/CSS 渲染，不得烘焙进图片。
