# AI伯乐 · 探索星球（整合平台 1.0）

儿童天赋发现平台的统一入口。聊天观察、故事共创、深海基地重建和职业模拟器四个模块均已迁入本项目，四者地位平等，可从探索星球上的对应大陆进入。“我的作品”和“成长足迹”也已成为平台内部的完整儿童页面，不再是占位内容。

## 项目结构

```text
整合平台1.0/
├─ app/                         星球首页与平台界面
├─ public/                      平台贴图和公共资源
│  └─ assets/collections/       作品与成长足迹的水彩插画
├─ modules/
│  ├─ chat/                     倾听之洲 · 聊天观察
│  ├─ story/                    想象之洲 · 故事共创
│  │  ├─ backend/
│  │  └─ frontend/
│  ├─ deep-sea/                 创造之洲 · 深海基地重建
│  └─ career/                   未来之洲 · 职业模拟器
├─ scripts/                     统一服务配置与工具
├─ 安装全部依赖.ps1
├─ 启动全部服务.ps1
├─ 检查服务状态.ps1
└─ 停止全部服务.ps1
```

## 我的作品与成长足迹

- 点击主星球附近的“我的作品”或“成长足迹”星石即可进入；顶部导航和浏览器前进、后退同样可用。
- 两个页面共用统一账号，并从 `http://localhost:8020/api/explorer/collection` 读取真实证据记录。
- 当前账号还没有探索记录，或后端暂时不可用时，页面会显示明确标注的示例内容，不会把示例当成孩子的真实档案。
- “我的作品”不再重复罗列全部历史，而是从四个模块各选出一枚高光（如最长故事、最快通关），用透明立体书贴纸呈现，并保留详情阅读、中文朗读和字号切换。
- “成长足迹”从账号注册日开始，按模块展示首次使用、最近使用、累计次数与可用的累计时长；仍包含星路手账、未点亮提示和作品互跳。
- 桌面、平板和手机布局均保留大点击区域、键盘焦点、减少动态偏好和清楚的加载/错误状态。

四个模块的运行路径全部指向 `modules/`，不再依赖项目外部的旧目录。旧目录暂时保留，仅作为安全备份。

## Windows 环境要求

- Node.js `>=22.13.0`
- Python `>=3.8`

## 首次安装

在 PowerShell 中运行：

```powershell
.\安装全部依赖.ps1
```

脚本会为平台、聊天观察、故事共创前端、深海基地前端安装 Node.js 依赖，并为三个 Python 后端安装依赖。

## 一键启动全部模块

```powershell
.\启动全部服务.ps1
```

脚本会按需启动平台、统一账号、天赋报告和四个探索模块所需的九项服务，并打开 <http://localhost:4173>。日志统一写入 `.runtime/logs/`。

```powershell
.\检查服务状态.ps1
.\停止全部服务.ps1
```

停止脚本只停止本启动脚本记录的进程，不会结束电脑上的其他 Node 或 Python 进程。

## 只启动或检查整合平台


```powershell
npm run dev
npm run build
npm test
```

`npm test` 会依次执行正式构建、页面与数据契约测试、一键启动记录兼容测试，以及统一账号服务的后端测试。首次运行前请先执行 `安装全部依赖.ps1`。

也可以运行 `.\启动平台.ps1` 或 `.\构建检查.ps1`。
