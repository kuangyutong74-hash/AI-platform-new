# AI伯乐 · 探索星球（整合平台 1.0）

儿童天赋发现平台的统一入口。聊天观察、故事共创、深海基地重建和职业模拟器四个模块均已迁入本项目，四者地位平等，可从探索星球上的对应大陆进入。

## 项目结构

```text
整合平台1.0/
├─ app/                         星球首页与平台界面
├─ public/                      平台贴图和公共资源
├─ modules/
│  ├─ chat/                     倾听之洲 · 聊天观察
│  ├─ story/                    想象之洲 · 故事共创
│  │  ├─ backend/
│  │  └─ frontend/
│  ├─ deep-sea/                 创造之洲 · 深海基地重建
│  └─ career/                   未来之洲 · 职业模拟器
├─ scripts/                     统一服务配置与工具
├─ 安装全部依赖.ps1
├─ 启动全部服务.ps1
├─ 检查服务状态.ps1
└─ 停止全部服务.ps1
```

四个模块的运行路径全部指向 `modules/`，不再依赖项目外部的旧目录。旧目录暂时保留，仅作为安全备份。

## Windows 环境要求

- Node.js `>=22.13.0`
- Python `>=3.8`

## 首次安装

在 PowerShell 中运行：

```powershell
.\安装全部依赖.ps1
```

脚本会为平台、聊天观察、故事共创前端、深海基地前端安装 Node.js 依赖，并为三个 Python 后端安装依赖。

## 一键启动全部模块

```powershell
.\启动全部服务.ps1
```

脚本会按需启动平台和四个模块所需的七项服务，并打开 <http://localhost:4173>。日志统一写入 `.runtime/logs/`。

```powershell
.\检查服务状态.ps1
.\停止全部服务.ps1
```

停止脚本只停止本启动脚本记录的进程，不会结束电脑上的其他 Node 或 Python 进程。

## 只启动或检查整合平台

```powershell
npm run dev
npm run build
npm test
```

也可以运行 `.\启动平台.ps1` 或 `.\构建检查.ps1`。
