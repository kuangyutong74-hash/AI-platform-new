# 阿拾旅程 · 四模块串联方案（绘本式外壳）

> 对齐文档：`docs/儿童探索旅程与统一水彩绘本UI设计方案.md`
> 目标：在「AI伯乐计划」脊柱（聊+玩→证据中心→八维→报告）之上，套一层**故事壳**——孩子不是"打开四个模块"，而是在阿拾陪伴下"经历同一趟探险"。
> 本方案遵循用户要求：**不硬聊、不固定死、不新增职业模块**；聊天是唯一主入口，三张故事卡对应三个模块，职业由阿拾引导体验。

---

## 一、故事壳一句话

孩子降生时对应一颗"天赋星球"。今天星球背面藏着一颗忽明忽暗的小星和一封没写完的来信——阿拾邀请孩子一起去看看到底怎么了。由此自然进入聊天，再沿着"补完故事 / 修个家 / 当一天小帮手"三张故事卡，走完同一次探险，最后把光收进拾光手账。

向导 **「阿拾」** = 拾光鸟（水彩小鸟，非拟人化老师），从星球后面飞出（墨点特效），是贯穿全程的同行者。

---

## 二、完整交互流程（每一步：触发 / 交互方式 / 视觉 / 数据）

### 步骤0 · 登录着陆（星球 + 阿拾飞出）
- **触发**：登录后进入探索星球主页。
- **交互方式**：无操作，自动播放。星球居中、缓慢自转；阿拾从星球**背面**飞出（墨点晕开 → 小鸟沿弧线飞出落至星球旁），2.2s 内完成（可在 `prefers-reduced-motion` 下直接显示终态）。
- **视觉**：深靛蓝水彩星夜 + 奶油绘本纸；阿拾形象见 `demo/A_cute_small_round_watercolor__2026-09-01T03-27-41.png`。
- **数据**：仅加载 `childId`、上次 `journeyId`（决定是否显示"继续上次种子"）。

### 步骤1 · 开场白 + 发现事件（自然引出聊天）
- **阿拾**："嗨，我是阿拾……今天星球背面好像发生了点事，你愿意陪我去看一眼吗？"
- **交互方式**：单主按钮"陪阿拾去看看 ✶"。
- **发现事件**：星球背面出现**一颗忽明忽暗的小星 + 一封没写完的来信**（可视化线索），阿拾说"有人需要帮忙，我们去看看它怎么了好吗？" → 按钮"去瞧瞧它怎么了"。
- **关键点**：首屏**没有空白输入框、没有"你想聊什么"**，先给一个具体事件让孩子反应 → 解决冷启动。

### 步骤2 · 聊天主入口（把"看"变成"说"）
- **阿拾提问（先点选，再表达）**：
  1. "你先看见了什么？" → 4 个图像/短句选项（发抖 / 眨眼 / 身边空空的 / 不知道）
  2. "如果可以问它一句，你想问什么？" → 3 选项 + 自由输入框"或者你自己问一句"
- **交互方式**：点选高亮（铅笔圈），允许一次修改；自由输入与语音同等权重；始终有"不想说这个"。
- **收口**：选完/说完后出现"把它记成一颗种子 →"。这句孩子的话成为贯穿全程的 **`seed`**（首个证据事件，source=chat）。
- **数据**：向 `platform-core /evidence` POST `EvidenceEvent{source:'chat', seedId, dimension:'待定/全维度初判', content}`；建立 `journeyId`。

### 步骤3 · 三张故事化选择卡（对应三个模块，但不写模块名）
- **阿拾**："现在我们要帮它，你想先看看哪一张？三条路都能帮到它。"
- 三张卡片均为**故事事件**而非产品名：
  | 卡面（儿童看到） | 对应模块 | 章节色 |
  |---|---|---|
  | 📖 把它的故事补完（没写完的故事页） | 故事共创 | 旧玫瑰粉 |
  | 🌊 动手帮它修个家（坏掉的基地） | 深海基地 | 海蓝+青绿 |
  | 🤝 去当一天小帮手（工作邀请函） | 职业体验 | 琥珀黄 |
- **交互方式**：卡片错落夹在书页中，点击当前卡先展开场景再进入；选哪张决定先进入哪个**章节**，但都遵循"故事—建造—职业—回顾"骨架（选择改变细节，不切断主线）。
- **接住 seed**：进模块时把 `seed` 注入开场白（如"你刚才说它『发抖』，我们就从这里把故事补完吧"）。

### 步骤4 · 模块内（玩 + 实时 emit 维度证据）
- 每个模块沿用现有玩法，只加**统一旅程页签顶栏 + 接住开场 + 回写**。
  - 故事共创：补全小海龟记忆 → emit(`language`)
  - 深海基地：安置伙伴/点亮路线/协商 → emit(`spatial`+`natural`)
  - 职业体验：现有六职业场景 → emit(`interpersonal`/`intrapersonal`/`logical`)
- **交互方式**：模块内"任务画页"带场景画+线索+预计时长；完成后"记一笔，回到星球"。
- **数据**：每次关键选择/原话 → POST `EvidenceEvent{source, seedId, dimension, content}`。

### 步骤5 · 职业引导（不固定为第四卡，由阿拾引导）
- 完成故事/深海后，阿拾**推荐**而非强制：
  > "你一路都在留意它有没有受伤。社区医生会照顾不舒服的人，动物保护员会照顾需要帮助的小动物。你想先去哪一个？"
- **交互方式**：六岛水彩职业地图——上层放大 2 个推荐（写明原因），下层 6 座等权小岛（已体验的插书签）。提供"看看全部六个职业""这次先不去了"。
- **不新增职业**：只用现有 6 个（doctor / firefighter / teacher / chef / journalist / animal_caretaker），只做"如何进入现有职业"的桥接文案与入口参数。

### 步骤6 · 收尾回顾（把光收进书里）
- 回到聊天，阿拾展示 3 件真实成果（记忆画页 / 基地剖面 / 体验记录卡），提 3 个复盘问题，生成"拾光书签"，命名并收藏到**我的作品 / 藏宝星图**（儿童端）；成人端同步**报告 / 成长足迹**。
- **数据**：按 `journeyId` 聚合所有 `EvidenceEvent` → 八维模型 → 双端输出。

## 三、如何接入现有平台

| 层 | 现有资产 | 本方案改动 |
|---|---|---|
| 旅程容器 | `app/`（vinext, 端口4173） | **新增**「绘本式聊天旅程容器」路由（首屏=星球+阿拾+发现事件+聊天+三卡），作为唯一主入口 |
| 阿拾角色 | 无（仅有 `partner-icebreaker.html` 的"小星"星形） | 用 `demo` 的阿拾形象 + 8 姿态（探头/倾听/指向/思考/飞行/记录/递书签/休息）；以组件形式注入各模块角落 |
| 三模块 | `modules/story`(5174) `modules/deep-sea`(3001) `modules/career`(8000) | 各自**只加**：统一旅程页签顶栏、接住 `seedId` 的开场、完成后写回 `journeyId`；**不改**核心玩法 |
| 证据中心 | `modules/platform-core`(8020) | 提供 `POST /evidence` 与 `journey` 读写；`EvidenceEvent` 统一结构（见下） |
| 输出端 | 我的作品/藏宝星图、报告/成长足迹 | 按 `journeyId` 聚合展示，不拆成三次孤立活动 |

### 跳转协议（子模块只读取，不重判兴趣）
```
?journeyId=...&chapterId=...&themePackId=...&taskId=...&returnUrl=...
```
子模块完成后向 `platform-core` 写入章节结果，再翻页返回聊天原位置（"这页我替你夹好书签了"）。

### 证据事件最小契约（贯穿聊→玩→模型）
```ts
interface EvidenceEvent {
  id: string; childId: string; journeyId: string;
  source: 'chat' | 'story' | 'deepsea' | 'career';
  seedId: string;                       // 把"聊→玩"串起来的键
  dimension: 'language'|'spatial'|'natural'|'interpersonal'|'intrapersonal'|'logical'|'待定';
  signalType: 'text'|'choice'|'drawing'|'audio';
  content: string; strength?: number; createdAt: string;
}
```

## 四、与《AI伯乐计划》脊柱对齐

```
聊(阿拾发现事件→种子) + 玩(故事/深海/职业)
        │  emit EvidenceEvent(seedId, dimension)
        ▼
   证据中心 platform-core  ──►  八维画像模型
        │                          │
        └──►  儿童端：我的作品 / 藏宝星图（八维镜像）
             成人端：天赋报告 / 成长足迹（培养建议）
```
「察」通道（家长/教师观察）按用户决定暂不接入。
